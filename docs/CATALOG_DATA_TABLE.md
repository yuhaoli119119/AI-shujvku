# 正文编号、补充资料与来源化数据表

文献计数只包含正文；显式 SI 类型或 SI 关系目标均排除。正文在各库内按 created_at、UUID 排序共用数字序号，类型只决定字母；SI 沿用所属正文数字。编号服务对目录修改取事务锁，移库携带关联 SI，保留原 UUID 与 AuditLog 中旧号/新号。GET、排序、筛选与启动不重排编号。

`backend/scripts/reassign_paper_codes.py` 默认只预演，`--output` 必须是项目内尚不存在的文件。应用需 `--apply --backup <已有完整备份>`，并在单事务内锁定 papers、paper_relationships，更换库内唯一约束、重排并审计；失败整体回滚。备份恢复应先在独立数据库验证，正式恢复按项目破坏性操作规则单独审批。不能用重新解析恢复编号。

详情显示概览、计算数据、实验数据、图片、原文表格、补充资料、章节。当前数据按明确材料/载体/位点分组；条件独立保留，多值展开后编辑。模板提供中文指标元数据，全部已存字段保留，模板外字段进入其他指标。历史数据折叠保留，显式转入要求历史记录 ID、材料/条件、已登记 PDF 页码与理由；服务器读取原值，不接受客户端指定科研值。缺失历史值保持为空并说明原因，区间值保留上下界文本且不生成单一数值；估读区间须明确核对边界后再转入。

数值编辑 PUT `/api/rebuild/values/{id}` 要求工作台会话、CSRF、`expected_revision`、`request_id` 和理由。旧值、来源和审计保留；冲突返回 409，同请求同内容可重放。GET `/api/rebuild/values/{id}` 用于保存后和超时后的回读。请求结果未确认时浏览器保留请求，回读核实后复用原字节，不能生成新的请求冒充重试。

附件集合兼容旧 SI Paper 和正文登记的 SI 文件，按实际路径/文件内容去重；无归属附件单独展示，须用户显式关联。列表 PDF 统计只计算正文 PDF，SI 科研数据及原详情链接继续保留。

本轮备份、编号预演和测试证据位于服务器 `outputs/catalog-table-20261011/`，不进入 Git。发布必须核验 GitHub 提交、部署提交、数据库回读和真实 Chromium 页面；用户操作体验仍需用户最终验收。
