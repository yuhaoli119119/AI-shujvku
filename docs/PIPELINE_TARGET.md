## 0. 总体形态

用户入口以原版成熟页面为基础：**文献库、详情、PDF/SI 查看保持原布局**；新 AI 图表整理、AI 数据表和汇总分析只通过“AI 提取 / 更多 / 更多操作”最小接入。
中间的解释、裁图、填表、去重、归类、标准化全部由 AI 完成，并把每一步的来源写清楚。

## 1. 上传与关联（第一步）

1. 上传正文 PDF 与 SI，系统**只保存文件与论文的关联**（谁是谁的补充材料、属于哪个 `paper_id`）。
2. **已退出旧的自动解析链**：新上传不再默认触发"自动全篇解析 → 自动生成待审核对象"的流程。
   文件是否解析、解析到哪一步，由一键 AI 提取或手动操作显式决定。
3. 论文与文件必须一对一可追溯；SI 只允许与它所属论文互相引用，**不得跨文献混用证据**。

## 2. AI 整理图表（第二步）

对当前 `paper_id` 的全部图表：

1. **裁图**：从 PDF 中裁出真实图/表对象（图像按页裁，表格按表对象）。
2. **合并跨页表**：同一张逻辑表被拆到多页时合并为一条表对象，保留各页来源。
3. **逐个解释子图**：复合图的每个子图（(a) (b) (c)…）单独给中文说明，不允许用 "(a-c)" 一句带过。
4. 每个图表/子图必须保留：
   - 来源论文（`paper_id`）与来源文件（正文 / SI）
   - 图号或表号、PDF 页码
   - 原文标题或图注（caption）
   - 坐标轴含义、单位
   - 涉及的**材料关系**（材料 ↔ 构型 ↔ 位点 ↔ 吸附物 ↔ 反应步骤）
5. **正文上下文**：图表结论必须能回指正文中对应的描述段落；正文与图表不一致时，两者都保留并标出冲突，不擅自二选一。
6. **展示分开，验收合并（2026-10-09 用户要求）**：详情页“图片”和“表格”分别展示，详细解读默认折叠。图表模块只展示最终版本，不再提供其他裁剪或历史版本入口；正文表格直接展示表格文本、单位和脚注，不使用截图作为主要内容。历史记录及重复图片按具体文献确认清单清理，保留最终来源绑定。不同正文版本、SI 和子图不能仅凭编号合并。验收仍按一篇文献的正文及明确关联 SI 的完整图表清单一起进行，逐项核对图/表编号、页码、裁剪完整性、图注/表题、解读与数据来源。不能因为图片模块通过就宣称该篇图表全部验收；表格缺失必须记录并继续核查。

## 3. AI 按反应模板填表（第三步）

### 3.1 模板

按反应类型分模板，至少覆盖：

- **SRR**（硫还原反应）
- **HER**（析氢反应）
- **OER**（析氧反应）
- **ORR**（氧还原反应）
- **CO2RR**（二氧化碳还原）

每个模板同时容纳 **实验（experimental）** 与 **DFT（计算）** 两类数据，字段以模板为准，两类数据不得混在同一行。

### 3.2 分类维度（必须分开）

- **单原子 / 双原子**：分开统计与填表，不合并成"原子级催化剂"一栏。
- **载体**：单原子/双原子的载体类型单独成列，不与活性中心混写。
- **支持石墨炔及其衍生物**：作为一等公民的材料族，允许按衍生物再细分。
- **新材料族**：分类是可扩展的枚举 + 自由补充字段，不写死成有限几类。

### 3.3 预设专题（可以扩展，不是上限）

模板默认带以下专题列，但**预设列不是字段上限**：

- 结构电子性质（如带隙、态密度相关描述、电荷转移等）
- 吸附稳定性（吸附能/结合能及其含义）
- 硫中毒（硫物种吸附/中毒相关指标）

需要新增性质时，直接加列/加组，不改模板语义；新增字段同样要满足第 4 节的数据规则。

### 3.4 填表要求（摘要，完整规则见 `DATA_RULES.md`）

- 数值保留**原始精度**；估算值最多两位小数，并标记"估读，不是精度承诺"。
- 看不清 / 不确定就**留空**，不留 0、不留猜测值。
- 材料、构型、位点、条件不同 → **分行**，不合并。
- 每个单元格都要能追到来源（论文/文件/页码/图号表号/单元格位置/原文片段）。

## 4. 汇总分析（第四步）

1. 分析时**只筛出本次需要的字段**，不要求整行字段齐全。
2. **不以"ML 就绪"作为入库门槛**：数据只要来源清楚就可以入库；
   是否适合进训练集是分析阶段的选择，不是入库的准入条件。
3. 汇总表按 `paper_id` 可下钻回原始证据。

## 5. 去重与冲突（贯穿第二、三、四步）

见 `DATA_RULES.md` 第 3 节。要点：同一 `paper_id` 内正文、SI、图表、表格重复出现的数据去重并保留全部来源；
明确值优先于同一结果的估读值；不同条件不合并；冲突只做局部处理，不阻塞整篇论文。

## 6. 保留项（重建过程中不得牺牲）

- 数据资产：数据库、`data/storage` 下的 PDF/SI、`data/libraries`、docling 缓存、备份。
- 现行登录接入：工作台登录方式维持现状（见 `auth/WORKBENCH_LOGIN.md`）。
- 安全边界：服务器仅限服务器内操作、凭据不外传、删除需授权（见仓库根 `AGENTS.md`）。
