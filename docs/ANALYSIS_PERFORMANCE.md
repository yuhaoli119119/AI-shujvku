# 数据分析与 DFT 页面性能

2026-10-30 候选；生产是否部署以发布回执为准。

- DFT 表格与辅助统计并行读取。统计请求失败保留筛选；旧文献库响应不会覆盖当前选择。
- DFT 查询先建立轻量排序索引，再通过原投影读取当前页完整记录和证据；不删减保存的数据、原值、来源或历史。
- PostgreSQL 可见行版本指纹检查插入、删除、同数量修正与表重写；论文展示字段仍计算内容指纹。缓存不依赖行数或时间有效期判断数据是否更新。
- 投影、DFT 索引和科学结果按数据库、范围及参数隔离；同查询冷构建合并，不同查询不共用长时间全局构建锁。
- 科学结果缓存最多 32 条、32 MiB；DFT 索引最多 8 项且按 128 MiB 预算淘汰。缓存不包含用户导出权限；每请求重新计算权限。
- 矩阵与散点下钻支持 gzip，客户端不支持时仍返回普通 JSON。数值、来源和统计口径保持一致。
- 关系散点图先请求服务端预渲染 SVG，再请求 `view=compact` 的配对数据切换到可交互层。compact 保留坐标、统计、可比组、候选路径和 source ID，去掉仅用于完整审计的 `record_sources` 与 `excluded_details`；不带 `view` 的完整接口合同不变。
- SVG 缓存键绑定当前数据 revision、文献库/过滤范围、字段、门槛和渲染器版本；磁盘缓存有文件数与字节上限，响应带 ETag、`no-cache` 再验证和 SVG 安全头。数据 revision 变化不会复用旧图。
- 静态图先到时先显示；compact 先到时静态图不得在之后覆盖交互层。字段快速切换和旧请求回调只允许最新请求更新页面。
- 分析页后台版本检查间隔 60 秒，隐藏页面暂停检查；刷新按钮可主动重新读取。

## 验证边界

证据保存在 `outputs/ui-performance-20261029/`，不提交业务数据。

2026-10-30 的关系图静态预览基准使用同一份只读完整响应（79 点、10 个可比组）：完整 JSON 为 3,267,506 字节，compact JSON 为 188,867 字节（5.78%），服务端 SVG 为 21,958 字节；SVG 已用独立 XML 解析器和真实浏览器静态渲染核验。产物及哈希位于 `outputs/visual-static-render-20261030/`。这是候选渲染基准，不代表生产页面已切换。

同一生产只读快照的 114,300 条 DFT 记录，抽查首/中/尾分页与两种排序的完整响应哈希相等；更早快照的 103,100 条完整投影哈希相等。候选服务的数据库连接强制只读，没有启动迁移、写接口或后台业务任务。

候选实测：冷 DFT 首屏约 21.84 秒降至 4.03 秒，后续页约 0.25–0.27 秒。预热后的表格、统计、字段、矩阵和下钻接口约 0.28–0.53 秒。首次大规模统计仍可能耗时十余秒，不将缓存命中速度表述为冷启动速度。
