# 更新记录

### 2026-10-21

- 修复：旧图表、表格与解读来源缺少新增字段时，按已登记原 PDF 恢复页码跳转，无需迁移数据或重新核验文献。
- 修复：旧 Word 导入已单独登记阅读 PDF 时，按原先保存的阅读文件跳页，兼容同时保留原 Word 哈希的来源。
- 优化：统一兼容旧顶层和新嵌套来源格式，保留实际文件或哈希冲突保护，以及 DOCX 派生阅读版本边界；原有资料与审核记录保持不变。

### 2026-10-20

- 修复：有原件哈希的历史 PDF 图表和解读证据可安全跳到对应页，原件变化或派生阅读版本不明时仍提示核对。
- 修复：新裁图保留实际裁切区域及跨页顺序，便于对照完整子图、坐标轴和图注。
- 修复：数据表来源按钮核对原件与阅读件版本，DOCX 原件定位不再误作 PDF 物理页跳转。
- 优化：旧原生 PDF 来源可按登记原件跳页，并保留旧页码待核对提示；不把历史来源升级为已审核。

- 新增：来源可保留历史状态与变更原因，当前分析仅使用仍有效的证据，历史记录继续可查。
- 修复：章节按原文顺序显示，标题已有编号时不再重复添加，历史章节保留独立查看。
- 优化：DOCX 图表与数据来源区分原件和派生阅读 PDF；页码身份未核实时提示核对并提供原件下载，已核实的阅读页按对应版本安全回看。

### 2026-10-18

实际可用版本以发布回执和页面验收为准。

- 修复：提取状态回报兼容已有请求格式；图表未提供新解读时保留已有内容，继续拒绝空结构和互相冲突的解读。
- 新增：提取指引明确区分迁移与分解势垒、吸附自由能与反应步骤自由能，要求保留原文对象、步骤和计算条件，未知项不补猜。
- 修复：专用物种字段与原文对象矛盾时不再进入自动分析，保留原始数值与来源；配对结果保留两侧完整计算条件。
- 新增：图像载体可按批只读检查坐标、文件和解码尺寸，明确已查与未查范围；机械检查独立报告，不代替原图视觉核对和科学验收。
- 新增：可只读对照历史尝试、原始状态与受控历史验收报告，区分未知执行、历史结束和明确替代声明；旧结论按原文范围与版本提示，未核准不自动转为当前验收。旧失败仅在真实导入或合法修正证据唯一对应时识别恢复，待核实不等于数据错误。
- 新增：详情页可只读查看来源、清单、补项、核对和交接建议；范围检查绑定当时的文件、计划、输出及导入回执，变化后提示重核，未知或部分导入不显示为全篇完成；旧修正与当前回执的对应待核实不等于数据错误，可结合原文和人工复核记录判断，科学验收仍单独进行。
- 新增：原文覆盖清单可声明正文与补充材料中的对象、材料条件和具体结果对应，区分待处理、未知、未报告与不适用；缺项、过期及具体对应结果可只读查看，按正文/SI和对象名称定位，精确标识可展开；清单不代表科学验收通过。
- 新增：数据批量导入可先预检查且不保存；回执明确部分保存、拒绝、身份待定与冲突，并提供保留行身份的失败项补交建议。
- 修复：编辑数据格时，重输含原文负号或明确科学计数形式的原值，继续保留对应分析数值；原始字符、精度、单位和来源保持不变，无法确定的表达仍保留原文并让数值留空。

### 2026-10-17

处理队列和原生自动停止默认关闭；同账号独立验收授权与原生调度仍需单独接入验收，实际版本以发布回执为准。

- 修复：数值导入支持原文负号与明确科学计数形式，保留原始字符、精度和来源；歧义表达仍提示核对，不猜测数值。
- 修复：新整理表格仅有原样文本时，详情页仍可安全查看和复制正文，表号按数字顺序排列（如 S1、S2、S10）；保留跨页来源、原始精度、非数值标记与空缺。
- 修复：仅有原始文本的表格明确标为待结构化，不能直接通过完整表格验收；正式表格也须核实本篇文件与物理页。来源匹配的旧表正文继续兼容，其修改会使旧冻结验收失效。
- 新增：图表和数据导入提供可追溯的逐项写入回执，支持相同请求重试核对；裁图失败不覆盖旧图片。
- 新增：提取与独立科学验收分别显示，文件或结果变化后提示重新验收，未复核内容不自动升级为通过。
- 新增：默认关闭并暂停的处理队列、暂停控制及验收待办，空完成或停滞提示人工核对，不自动重派或切换模型。
- 优化：大篇文献工作包明确分页，阅读资料支持按来源版本复用分页文本、页面图像和图表清单。
- 优化：工作包支持小首包与行、图表、章节、旧表正文分段读取，修订变化时拒绝混合；已有数据行批量读取，减少重复查询。
- 新增：详情页可主动只读检查已存结果缺项，列出来源、格式、物理页及修正指引；提取指引统一正式表格与来源合同，未知范围和原文未报告项保留诚实状态。
