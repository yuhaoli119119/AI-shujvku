# 更新记录

- 优化：中文阅读内容保存后可直接回看，刷新不重复生成；导读未完成可单独重试，不影响已有数据和普通解析。

- 修复：任务实际已运行或结束时可恢复正确状态，避免一直停在准备中；保留原任务与已有结果。
- 新增：选择正文与 SI 后一次启动普通解析，按文件展示原文读取、图表和数据进度；已有成果随时可看。
- 优化：局部文件或字段失败保留其他结果，可继续未完成范围；普通解析无需逐格审批，科学精修与独立审核可稍后进行。
- 修复：重复请求复用原回执，短时断网与限流采用有限重试；任务状态不明时保留原任务并核实，避免重复解析。
- 新增：DOCX 可按原文段落和表格位置读取与引用，无物理页时明确标示。

### 2026-10-18

实际可用版本以发布回执和页面验收为准。

- 修复：提取状态回报兼容已有请求格式；图表未提供新解读时保留已有内容，继续拒绝空结构和互相冲突的解读。
- 新增：提取指引明确区分迁移与分解势垒、吸附自由能与反应步骤自由能，要求保留原文对象、步骤和计算条件，未知项不补猜。
- 修复：专用物种字段与原文对象矛盾时不再进入自动分析，保留原始数值与来源；配对结果保留两侧完整计算条件。
- 新增：图像载体可按批只读检查坐标、文件和解码尺寸，明确已查与未查范围；机械检查独立报告，不代替原图视觉核对和科学验收。
- 新增：可只读对照历史尝试、原始状态与受控历史验收报告，区分未知执行、历史结束和明确替代声明；旧结论按原文范围与版本提示，未核准不自动转为当前验收。旧失败仅在真实导入或合法修正证据唯一对应时识别恢复，待核实不等于数据错误。
- 新增：详情页可只读查看来源、清单、补项、核对和交接建议；范围检查绑定当时的文件、计划、输出及导入回执，变化后提示重核，未知或部分导入不显示为全篇完成；旧修正与当前回执的对应待核实不等于数据错误，可结合原文和人工复核记录判断，科学验收仍单独进行。
- 新增：原文覆盖清单可声明正文与补充材料中的对象、材料条件和具体结果对应，区分待处理、未知、未报告与不适用；缺项、过期及具体对应结果可只读查看，按正文/SI和对象名称定位，精确标识可展开；清单不代表科学验收通过。
- 新增：数据批量导入可先预检查且不保存；回执明确部分保存、拒绝、身份待定与冲突，并提供保留行身份的失败项补交建议。
- 修复：编辑数据格时，重输含原文负号或明确科学计数形式的原值，继续保留对应分析数值；原始字符、精度、单位和来源保持不变，无法确定的表达仍保留原文并让数值留空。
