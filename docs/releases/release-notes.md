# 更新记录

### 2026-10-17

处理队列和原生自动停止默认关闭；同账号独立验收授权与原生调度仍需单独接入验收，实际版本以发布回执为准。

- 修复：新整理表格仅有原样文本时，详情页仍可安全查看和复制正文，表号按数字顺序排列（如 S1、S2、S10）；保留跨页来源、原始精度、非数值标记与空缺。
- 修复：仅有原始文本的表格明确标为待结构化，不能直接通过完整表格验收；正式表格也须核实本篇文件与物理页。来源匹配的旧表正文继续兼容，其修改会使旧冻结验收失效。
- 新增：图表和数据导入提供可追溯的逐项写入回执，支持相同请求重试核对；裁图失败不覆盖旧图片。
- 新增：提取与独立科学验收分别显示，文件或结果变化后提示重新验收，未复核内容不自动升级为通过。
- 新增：默认关闭并暂停的处理队列、暂停控制及验收待办，空完成或停滞提示人工核对，不自动重派或切换模型。
- 优化：大篇文献工作包明确分页，阅读资料支持按来源版本复用分页文本、页面图像和图表清单。
- 优化：工作包支持小首包与行、图表、章节、旧表正文分段读取，修订变化时拒绝混合；已有数据行批量读取，减少重复查询。
- 新增：详情页可主动只读检查已存结果缺项，列出来源、格式、物理页及修正指引；提取指引统一正式表格与来源合同，未知范围和原文未报告项保留诚实状态。

### 2026-10-16

- 新增：同事实数据可先预演完整来源合并方案，明确批准精确删除清单后再原子执行；保留全部来源身份、原始精度和完整历史，过期方案、重复请求内容冲突及引用冲突会被拒绝。
- 新增：已登记来源可通过正式鉴权接口修正文件归属、图表关联和表格坐标，保留来源身份、原值及完整修正历史；并发冲突会拒绝覆盖。
- 优化：数据分析复用经过数据内容校验的计算准备结果，减少矩阵和散点图的重复加载与计算；打开页面时只加载当前标签需要的数据。
- 新增：矩阵下方散点图提供“刷新小图”，可直接重新读取当前变量对。
- 修复：快速切换矩阵单元格时，旧图和旧请求结果可能与当前选择不一致；现在立即显示加载状态，仅更新最后选中的变量对，刷新矩阵后保留选择。
