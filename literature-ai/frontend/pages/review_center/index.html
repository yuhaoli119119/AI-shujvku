三种方式相互独立。先选择使用的 AI，再按下方步骤处理；所有任务仅限当前论文与明确关联 SI。

本地 AI 直连 MCP（无需下载）

适合当前电脑上已连接 Literature AI MCP 的 Codex 或其他智能体。直接读取最新任务、主文与关联 SI、PDF 页面、裁图、表格和证据，无需 ZIP，也无需先让网页 AI 处理。

读取不写库。修正、resolve、finalize、导入与批量应用需用户明确授权和现有 MCP 权限；写入后读取真实状态。完成子任务不等于整篇完成。

适合不能连接 MCP 的网页 AI。图表 JSON 在本页明确应用；DFT JSON 校验后按原有本地 AI 受控导入流程处理。

图表审核

离线图表审核：下载材料 → 返回 JSON → 页面校验 → 明确应用

使用图表审核包及其配套提示词。校验不写库；明确应用后写入图表建议。若服务器仍要求逐图 PDF 核验，可独立选择本地 MCP 方式继续；应用不代表整篇完成。

  1. 1
    下载图表审核材料

    下载当前固定审核范围的 PDF、图表与待填写 JSON。

  2. 2
    交给网页 AI

    复制与审核包配套的填写说明，网页 AI 应返回图表审核 JSON 文件。

  3. 3
    校验并决定是否应用

    支持图表审核 JSON。先校验；只有你在弹窗中明确点击“应用图表结果”才会写入当前范围。

DFT 全量审核包

全量审核已有 DFT，并扫描漏提数据

适合需要同时覆盖现有 DFT 结果和全部合格证据查漏的场景。审核包产出 DFT JSON；页面只校验，再复制本地 AI 受控导入指令。

  1. 1
    下载全量 DFT 审核材料

    包含已有 target、已审核图表证据和查漏范围。

  2. 2
    复制配套提示词

    网页 AI 应填写包内模板并返回严格的 DFT 审核 JSON 文件。

  3. 3
    回传并校验结果

    支持 DFT 审核 JSON。校验不写库；校验后仍需复制本地 AI 指令完成证据复核和受控导入。

此正式入口用于 DFT 字段核验；图表阶段不适用。字段核验 ZIP 冻结当前 pending 必审字段与证据；DFT 全量审核包则覆盖已有数据和漏提扫描，两者不能交换提示词。

字段核验 ZIP

核验当前 pending 的 DFT 必审字段

适合已连接 Literature AI MCP 的网页 AI。ZIP 只列当前 pending 字段，AI 通过 apply_ai_verification_batch 分批提交；返回真实回读，无需回传 JSON。字段任务为 0 时仅表示“当前没有 pending 字段任务”，不表示 DFT 或整篇完成。

  1. 1
    下载字段核验材料

    包含字段任务快照、主文、明确关联 SI 与定位证据。

  2. 2
    复制直连 MCP 执行说明

    交给已连接 MCP 的 AI；完成后查看批次真实回读，不需要把 JSON 回传本页。
